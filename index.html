What's included in this build

✂️ Clip creation

Backend-powered clip export using FFmpeg. Highlight ranking is an initial audio-activity baseline, not full semantic AI yet.

📱 Shorts format

Vertical 9:16 output with source-aware scaling and cropping.

💬 Captions roadmap

Caption rendering is the next module. Accurate automatic speech transcription needs a speech model and extra processing capacity.

⚡ Long streams

Designed for server processing. Five-hour uploads and five-minute turnaround are goals, not guarantees on free hosting.

Only upload videos you own or have permission to edit. Don't share private or confidential recordings. This demo requires the PeakCut backend to be running; GitHub Pages alone cannot process long videos.
